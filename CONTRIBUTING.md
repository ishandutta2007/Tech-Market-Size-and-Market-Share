# 🛠️ Developer & Contributor Guide

Welcome to the **Tech-Market-Size-and-Market-Share** repository! This project maintains a structured, data-driven database of global technology market sizes, enterprise revenues, gross merchandise value (GMV), and competitive market shares.

This guide provides instructions for developers and contributors on:
- How the repository is structured
- JSON Data schema rules
- How to run and update generator scripts
- How to add new sectors or future yearly datasets (e.g., `2027`, `2028`)
- How the Sankey diagram generator works

## 📊 JSON Data Schema (`data/market_share_<YEAR>.json`)

All sector market size figures and competitive rankings are decoupled into versioned JSON files inside the `data/` directory.

### Schema Definition:

```json
{
  "year": "2025–2026",
  "title": "Market Size and Market Share by Tech Sector (2025–2026 Estimates)",
  "total_revenue": "~$5.910 Trillion",
  "total_gmv": "~$31.3 Trillion",
  "sectors": [
    {
      "id": "unique_sector_id",
      "name": "Sector Display Name",
      "subtitle": "Scope / Subsectors Included",
      "revenue": "~$488 Billion",
      "gmv": "-",
      "leaders": [
        { "name": "Company A", "share": "18.0%" },
        { "name": "Company B", "share": "12.5%" }
      ],
      "note": "Optional footnote or structural market context"
    }
  ],
  "highlights": [
    {
      "icon": "🤖",
      "title": "Highlight Headline",
      "text": "Detailed qualitative insight and strategic analysis."
    }
  ]
}
```

### Data Rules & Guidelines:
1. **Revenue vs. GMV separation:**
   * **Revenue (`revenue`)**: Direct corporate revenue generated by platform/service providers (e.g. cloud subscription fees, software licenses, net ad revenue, commission cuts).
   * **GMV (`gmv`)**: Gross Merchandise Value or total transaction throughput across the ecosystem (e.g. total volume transacted on E-commerce platforms or crypto market cap). Do not mix GMV into the revenue column.
2. **Market Share Bracket Rule:**
   * Include every competitor with **$\ge 1.0\%$** market share with their share percentage specified in parentheses (e.g., `{ "name": "DeepSeek", "share": "4.5%" }`).
3. **No Slashes in Company Names:**
   * Keep separate companies as distinct list items (e.g. do not combine `DeepSeek / Zhipu AI` into a single entry).

## 🚀 Running the Generators

After editing or creating a dataset in `data/`, run the generator scripts to rebuild `README.md` and `assets/sankey.svg`.

### 1. Generating `README.md`

You can use Python, Node.js, or PowerShell:

```bash
# Python
python scripts/generate_readme.py --year 2026

# PowerShell (Windows native, zero-dependency)
.\scripts\generate_readme.ps1 -Year 2026

# Node.js
node scripts/generate_readme.js --year 2026
```

### 2. Generating `assets/sankey.svg`

The Sankey diagram calculates the dynamic value flow:
$$\text{Total Tech Market} \longrightarrow \text{Sectors} \longrightarrow \text{Conglomerates \& Ecosystems}$$

Run either:

```bash
# Python
python scripts/generate_sankey.py --year 2026

# PowerShell
.\scripts\generate_sankey.ps1 -Year 2026
```

## ➕ How to Add a New Sector

1. Open `data/market_share_<YEAR>.json`.
2. Add a new sector object inside the `"sectors"` array:
   ```json
   {
     "id": "cybersecurity",
     "name": "Cybersecurity",
     "subtitle": "Endpoint, Identity, SIEM & Cloud Security",
     "revenue": "~$190 Billion",
     "gmv": "-",
     "leaders": [
       { "name": "Palo Alto Networks", "share": "8.5%" },
       { "name": "CrowdStrike", "share": "6.0%" },
       { "name": "Microsoft (Security)", "share": "5.5%" },
       { "name": "Fortinet", "share": "4.5%" },
       { "name": "Cisco", "share": "4.0%" }
     ]
   }
   ```
3. Update `"total_revenue"` at the top of the JSON file to reflect the new sum.
4. If the sector introduces new subsidiary names for major conglomerates, add them to `COMPANY_MAPPINGS` in `scripts/generate_sankey.py` and `scripts/generate_sankey.ps1` (e.g. `"Microsoft (Security)": "Microsoft"`).
5. Re-run:
   ```bash
   .\scripts\generate_sankey.ps1
   .\scripts\generate_readme.ps1
   ```

## 📅 How to Add Future Yearly Datasets (e.g., 2027)

1. Create a copy of the previous dataset:
   ```bash
   cp data/market_share_2026.json data/market_share_2027.json
   ```
2. Update the market sizing figures, shares, and highlights in `data/market_share_2027.json`.
3. Generate the updated README and diagram:
   ```bash
   python scripts/generate_sankey.py --year 2027 --output assets/sankey.svg
   python scripts/generate_readme.py --year 2027
   ```

## 🌊 Sankey Diagram Implementation Details

The Sankey generator (`scripts/generate_sankey.py` / `scripts/generate_sankey.ps1`) produces pure, standalone vector XML:
- **Zero Third-Party Dependencies:** Uses standard library math and bezier cubic curve calculations ($C\ x_1\ y_1, x_2\ y_2, x\ y$).
- **Strict XML Compliance:** All text and tooltips are entity-escaped (`&amp;`, `&lt;`, `&gt;`, `&quot;`) to ensure valid rendering across all SVG engines and GitHub markdown.
- **Conglomerate Normalization:** Maps diverse product brands (e.g. AWS, Azure, YouTube, Instagram, Xbox, Gemini, Optimus) to their respective parent conglomerates (`Alphabet`, `Microsoft`, `Amazon`, `Apple`, `Meta`, `Tesla`, `Nvidia`, `Tencent`, etc.) to produce accurate conglomerate-level destination streams on the right side.
- **Collision-Free Typography:** Uses SVG presentation attributes with dual-sided text anchors (`text-anchor="end"` for sector labels, `text-anchor="start"` for company labels) to prevent overlap with bezier ribbons.

## ✅ Quality Checklist Before Committing

Before submitting a Pull Request:
- [ ] JSON is valid (`ConvertFrom-Json` or `json.load()` parses without errors).
- [ ] Total revenue row matches the sum of individual sector revenues.
- [ ] GMV is strictly kept in the `gmv` field and not mixed into `revenue`.
- [ ] `README.md` has been regenerated and reflects all JSON updates.
- [ ] `assets/sankey.svg` parses validly as XML (`[xml](Get-Content assets/sankey.svg)` in PowerShell or `xml.etree.ElementTree` in Python).
